Crie uma função chamada _update_inventory_ que recebe três parâmetros: _inventory_dict_ (um dicionário), _item_ (uma string) e _quantity_ (um inteiro).

A função deve atualizar o _inventory_dict_ com o novo _item_ e _quantity_. 

Se o item já existir no inventário, sua quantidade deve ser aumentada pela quantidade dada.
Se o item não existir, um novo item deve ser adicionado com a quantidade dada.

A função deve retornar o dicionário atualizado.
