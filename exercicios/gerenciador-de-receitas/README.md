# Gerenciador de Receitas

Você está gerenciando um livro de receitas digital onde cada receita é armazenada como um dicionário.

Cada dicionário contém o nome da receita como a chave e uma lista de ingredientes como o valor.

Sua tarefa é realizar várias operações para atualizar e gerenciar o livro de receitas.

### Criar o Livro de Receitas:
Crie um dicionário chamado recipe_book com as seguintes receitas:  
- _"Pancakes": ["flour", "milk", "eggs", "sugar"]_  
- _"Salad": ["lettuce", "tomato", "cucumber", "olive oil"]_

### Acessar Ingredientes:
Imprima a lista de ingredientes para _"Pancakes"_.

### Adicionar uma Nova Receita:
Adicione uma nova receita _"Smoothie"_ com os ingredientes _["banana", "milk", "honey"]_ ao dicionário.

### Modificar uma Receita:
Adicione _"blueberries"_ à receita _"Smoothie"_.

### Imprimir Todas as Receitas:
Imprima todo o dicionário _recipe_book_ para verificar as atualizações.
